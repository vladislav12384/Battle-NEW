# Battle — основа боевой системы

Фундамент кооперативного (до 4 игроков) экшен-файтинга от первого лица: детерминированная
физика боя, система комбо, защита и выходы из комбо, тренировочный полигон в браузере.

* **Ядро** (`src/core`) — чистая детерминированная симуляция на 60 тиков/с. Работает без
  движка и без браузера, поэтому годится и для сервера.
* **Контент** (`src/content`) — персонажи описываются данными (кадры, хитбоксы, отбрасывание,
  маршруты комбо). Эталонный боец — **Striker**, тяжёлый вариант — **Brute**.
* **Клиент** (`src/client`) — Three.js: вид от первого лица, процедурная анимация (удары идут
  точно по хитбоксам), эффекты попаданий, звук, HUD, режим тренировки.

Подробный разбор механик с формулами — в [docs/COMBAT_DESIGN.md](docs/COMBAT_DESIGN.md).

## Запуск на ПК

Нужен **Node.js 22.12 или новее**: скачай версию LTS с <https://nodejs.org> и установи с настройками по умолчанию.

**Windows, проще всего:**

1. На странице репозитория нажми **Code → Download ZIP** и распакуй архив в любую папку
   (или `git clone https://github.com/vladislav12384/Battle-NEW.git`).
2. Дважды кликни **`start-windows.bat`**. В первый раз он минуту ставит зависимости, затем сам откроет игру в браузере.
3. Кликни по экрану игры, чтобы захватить мышь. `Esc` — пауза. Чтобы выключить, закрой чёрное окно консоли.

**macOS / Linux:** `./start.sh` в папке проекта.

**Вручную (любая ОС):**

```bash
npm install        # один раз
npm run dev        # открой http://localhost:5173 и кликни по экрану
npm test           # тесты механик (vitest)
npm run build      # проверка типов и продакшен-сборка в dist/
```

Лучше всего работает в Chrome или Edge с включённым аппаратным ускорением.

Параметры URL для отладки:
`?third` — камера от третьего лица, `?hitboxes` — показать хитбоксы, `?enemies=3&allies=1` — состав боя,
`?dummy=block|parry|dodge|idle|fighter` — поведение врагов, `?level=easy|normal|hard` — сложность бота
(её же можно выбрать на экране старта или клавишей `8`), `?demo` — за тебя играет бот.

## Управление

Всего шесть кнопок.

| | |
|---|---|
| `WASD` / мышь | движение (и во время ударов тоже) / обзор — камера всегда твоя |
| `ЛКМ` | удары руками. Жми в ритм попаданий — каждый следующий удар новый: джеб → кросс → хук → апперкот → … |
| `ПКМ` | мощный удар. Сразу — хеймейкер (держи — заряд); в серии — добивание, тем мощнее, чем длиннее серия: круговой, бэкфист, подброс, топор |
| `ЛКМ` + `ПКМ` | бросок (пробивает блок) |
| `E` | ки: волна, `W`+`E` таран, `S`+`E` неуязвимый «дракон»; при полной шкале ки — супер |
| `Space` | прыжок, двойной прыжок, прыжок за подброшенным противником |
| `Shift` | рывок; `Shift`+`A`/`D` — уклон вбок по дуге вокруг врага; держать — бег; в падении — встать перекатом |
| `F` | держать — блок, нажать в момент удара — **парирование**; под серией врага при полной шкале — **взрыв** |
| `H` | список приёмов; `8` — сложность бота; `1`–`7`, `V` — настройки полигона |

Ситуации: `S` + `ЛКМ` — толчок ногой, `S` + `ПКМ` — подсечка, бег + атака — колено / удар с разбега,
враг лежит — атака добивает. Захват цели (`Tab` / колесо) — по желанию.

**Ритм вместо закликивания**: следующий удар жми в момент попадания (у прицела вспыхивает кольцо),
каждая связка в ритм бьёт сильнее. Нажатие во время замаха ломает серию.
**Индикатор у прицела** показывает, откуда летит удар врага (белый — быстрый, оранжевый — тяжёлый,
красный — неблокируемый). Уйти рывком можно от любого удара: удар слева → рывок вправо.
От тяжёлых увернуться легко и по реакции, от быстрых — надо предугадать. Рывок впритык —
**идеальный уклон**: противник замедлен, бей в ответ. Тяжёлые удары не сбить джебом на замахе.
Жёлтая шкала — **выносливость**: её тратят удары, рывки, бег и удары в блок, попадание часть возвращает.
Поддерживается геймпад: X/Y — атаки (вместе — бросок), A — прыжок, B — рывок, RB — блок, RT — ки.

## Что уже есть

* Выносливость: удары, рывки, бег и блок её тратят, попадание часть возвращает; изнеможение
  замедляет и ломает стойку. Промахи стоят времени, выносливости и позиции.
* Управление: камера никогда не перехватывается, подстраховка прицела доворачивает только тело
  (до 12°), можно двигаться во время ударов, финты, медленный поворот блока (заход сбоку работает).
* Простое управление: две кнопки атаки, удар зависит от позиции в серии (около 35 приёмов у
  эталонного бойца), «приедаемость» однотипных ударов, бросок двумя кнопками.
* Кинематическая физика: гравитация, вес, стены и столбы, wall splat и wall bounce, отскок от земли,
  расталкивание тел, хитстоп, вертикальный прицел ударов по камере.
* Лаунчеры и воздушные комбо, заряжаемые удары, снаряды, контр-удары, клинчи ударов, Ki Cancel.
* Лимиты комбо: скейлинг урона, распад хитстана, рост гравитации, очки джаггла, ограничение ударов по лежачему.
* Умный бой вместо закликивания: связки только в ритм ударов (закликивание блокирует связку),
  стойкость тяжёлых ударов против лёгких, «камень-ножницы-бумага» из ударов, рывков, блока и бросков.
* Рывки: от любого удара можно уйти, окно зависит от удара (тяжёлые — легко, быстрые — на опережение)
  и от стороны рывка; круговой рывок вокруг врага; идеальный уклон замедляет противника.
* Читаемость: индикатор входящих ударов у прицела, блик и звук замаха, кольцо ритма, послеобразы,
  аниме-кадр удара на контрах и нокаутах.
* Защита: блок по дуге, урон по стойке и её пробитие, парирование с защитой от спама
  (отражает снаряды), броня, рывки со штрафом за спам, броски и их разрыв.
* Выходы из комбо: Burst, тех в воздухе и на земле, перекат, жёсткий нокдаун, неуязвимый реверсал,
  подсветка «дыр» в комбо (TRUE COMBO / ESCAPABLE).
* Анимация на пружинах: замах, удар, доводка, работа всего тела, направленные реакции на удары,
  камера от первого лица привязана к телу.
* Кооператив: команды, общий счётчик комбо на жертве, без огня по своим, боты-союзники и боты-враги.
* Сетевая готовность: снапшоты, восстановление, хэш состояния; тесты на детерминизм и повтор ввода.
