# Battle — основа боевой системы

Фундамент кооперативного (до 4 игроков) экшен-файтинга от первого лица: детерминированная
физика боя, система комбо, защита и выходы из комбо, тренировочный полигон в браузере.

* **Ядро** (`src/core`) — чистая детерминированная симуляция на 60 тиков/с. Работает без
  движка и без браузера, поэтому годится и для сервера.
* **Контент** (`src/content`) — персонажи описываются данными (кадры, хитбоксы, отбрасывание,
  маршруты комбо). Эталонный боец — **Striker**, тяжёлый вариант — **Brute**.
* **Клиент** (`src/client`) — Three.js: вид от первого лица, процедурная анимация (удары идут
  точно по хитбоксам), эффекты попаданий, звук, HUD, режим тренировки.

Подробный разбор механик с формулами — в [docs/COMBAT_DESIGN.md](docs/COMBAT_DESIGN.md).

## Запуск на ПК

Нужен **Node.js 22.12 или новее**: скачай версию LTS с <https://nodejs.org> и установи с настройками по умолчанию.

**Windows, проще всего:**

1. На странице репозитория нажми **Code → Download ZIP** и распакуй архив в любую папку
   (или `git clone https://github.com/vladislav12384/Battle-NEW.git`).
2. Дважды кликни **`start-windows.bat`**. В первый раз он минуту ставит зависимости, затем сам откроет игру в браузере.
3. Кликни по экрану игры, чтобы захватить мышь. `Esc` — пауза. Чтобы выключить, закрой чёрное окно консоли.

**macOS / Linux:** `./start.sh` в папке проекта.

**Вручную (любая ОС):**

```bash
npm install        # один раз
npm run dev        # открой http://localhost:5173 и кликни по экрану
npm test           # тесты механик (vitest)
npm run build      # проверка типов и продакшен-сборка в dist/
```

Лучше всего работает в Chrome или Edge с включённым аппаратным ускорением.

Параметры URL для отладки:
`?third` — камера от третьего лица, `?hitboxes` — показать хитбоксы, `?enemies=3&allies=1` — состав боя,
`?dummy=block|parry|dodge|idle|fighter` — поведение врагов, `?demo` — за тебя играет бот.

## Управление

| | |
|---|---|
| `WASD` / мышь | движение / обзор |
| `ЛКМ` / `ПКМ` | лёгкий / тяжёлый удар (`ПКМ` держать — заряд) |
| `W/S` + удар | направленные приёмы (рывок, лаунчер, реверсал...) |
| `E` / `R` / `Q` | спецприём / супер (100 метра) / бросок |
| `Space` | прыжок, двойной прыжок, прыжок за подброшенным противником |
| `Shift` | уклонение с неуязвимостью, держать — бег. Во время атаки за 50 метра — Ki Cancel |
| `F` | держать — блок, нажать в момент удара — **парирование** |
| `X` | **Burst** — разрыв комбо |
| `Tab` / СКМ | захват цели |
| `1`–`7`, `V`, `H` | полигон: хитбоксы, режим манекена, замедление, сброс, +союзник/+враг, бесконечный метр, камера, список приёмов |

Поддерживается геймпад (стандартная раскладка Xbox).

## Что уже есть

* Кинематическая физика: гравитация, вес, стены и столбы, wall splat и wall bounce, отскок от земли,
  расталкивание тел, хитстоп, магнетизм ударов, вертикальный прицел ударов по камере.
* Комбо: строки с окнами отмен, проверенные формулой «настоящего комбо», отмены в спецприём, супер
  и прыжок, Ki Cancel, лаунчеры и воздушные комбо, заряжаемые удары, снаряды, контр-удары, клинчи ударов.
* Лимиты комбо: скейлинг урона, распад хитстана, рост гравитации, очки джаггла, ограничение ударов по лежачему.
* Защита: блок по дуге (фланги работают), урон по стойке и её пробитие, парирование с защитой
  от спама (отражает снаряды), броня, уклонения со штрафом за спам, идеальное уклонение, броски и их разрыв.
* Выходы из комбо: Burst, тех в воздухе и на земле, перекат, жёсткий нокдаун, неуязвимый реверсал,
  подсветка «дыр» в комбо (TRUE COMBO / ESCAPABLE).
* Кооператив: команды, общий счётчик комбо на жертве, без огня по своим, боты-союзники и боты-враги.
* Сетевая готовность: снапшоты, восстановление, хэш состояния; тесты на детерминизм и повтор ввода.
